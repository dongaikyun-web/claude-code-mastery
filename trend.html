수집 vs 보기 — 위쪽 수집 줄은 다음 수집에 어느 차트를 가져올지 정합니다. 아래 보기 줄은 이미 모아둔 데이터를 걸러 보여줍니다. 보기 드롭다운에는 실제로 수집된 국가·카테고리만 나타납니다.

지표
· 순위 — 해당 국가 인기 급상승 차트에서의 위치. 아래 화살표는 지난 수집 대비 변동.
· 현재 VPH — 최근 두 스냅샷 사이 조회수 증가분 ÷ 경과시간. 지금도 오르는지를 봅니다. 10분 이상 간격의 수집이 2회 필요합니다.
· 누적 VPH — 조회수 ÷ 업로드 후 경과시간. 1회 수집만으로 계산됩니다.
· 배수 — 조회수 ÷ 같은 채널 최근 영상(7일 이상 지난 것 최대 20개) 조회수 중앙값. 구독자 규모를 보정하므로 작은 채널의 대박을 찾아냅니다. 배수 일괄 계산으로 화면의 채널을 한번에 처리할 수 있습니다(채널당 3유닛).
· 참여율 — 좋아요 ÷ 조회수.

주의
· 스냅샷은 이 페이지를 열었을 때만 기록됩니다. 하루 한 번 열면 일간 추이가 쌓입니다.
· 카테고리별 인기 급상승 차트는 YouTube가 일부 카테고리에만 제공합니다. 결과가 0건인 카테고리는 목록에 차트 없음으로 표시해 두니 다른 카테고리를 고르세요.
· 데이터는 localStorage(약 5MB, 스냅샷 6만 건)에 저장됩니다. 브라우저 데이터 삭제 시 사라지니 백업을 주기적으로 쓰세요.
· API 키는 localStorage에만 저장되며 파일에는 기록되지 않습니다. 다만 브라우저 직접 호출 구조상 개발자도구로는 보입니다. 웹에 올릴 경우 Cloud Console에서 HTTP 리퍼러 제한을 거세요.
· file://에서 네트워크 오류가 나면 폴더에서 python -m http.server 실행 후 localhost:8000/trend.html로 접속하세요.
· 쿼터는 태평양시 자정(한국시간 오후 4~5시)에 초기화됩니다.
